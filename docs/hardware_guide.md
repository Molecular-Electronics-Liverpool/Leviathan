# Hardware Guide

This section is designed to assist setting up a similar STMBJ system to The Leviathan. Individual builds may vary but if built in exactly the same way (with consistent PXI card slots etc)  
then the software should control the STM relatively seamlessly. However, this is not guaranteed. We are happy to answer any questions regarding compatible hardware setup for groups  
designing their own instruments.

## Components

* BNC coaxial cables ($50{\ohm}$ impedance).
* Femto DLPCA-200 variable gain amplifier.
* Agilent 5500 SPM (details to come on scanner specifics etc - currently no longer being sold to my knowledge).
* National Instruments PXI (Details to come)
* Series Resistor box to protect overload during saturation (in voltage divider configuration).
